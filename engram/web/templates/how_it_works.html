  • Cheap eyes, expensive brain

    A fast model reads every frame. The strongest model only thinks, and opens an image only when it needs one.

  • Everything has a timestamp

    Each note, card and question quotes the lecture or points to a frame. Plain code turns that into a moment you can click.

  • Checked, not trusted

    A second model tests every answer against the lecture, and anything it can't find there is removed.

  • Measured on real lectures

    On a person's answer key, Engram caught 22 of 23 board changes in Stanford's CS229, and 5 of 5 in MIT 18.06.
